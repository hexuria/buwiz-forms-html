# 1601-EQ fixtures

These fixtures use synthetic values only. They do not contain real taxpayer data and are not submission payloads.

- `positive-minimal.json` is the smallest source-derived local Validate scenario with Item 4 set to No.
- `negative-cases.json` covers ordered Validate/Save failures and audited implementation defects.
- `calculation-boundaries.json` pins formulas, effective-year ATC overrides, and known package-catalog discrepancies.
- `atc-catalog-v796.json` is generated by `rules/tools/extract-1601eq-atc-catalog.ps1`.
- `runtime-control-inventory-v796.json` is generated by `rules/tools/extract-1601eq-controls.ps1`.
- `live-ui-observations-v1.json` records two exact safe Validate dialogs and discloses incidental synthetic navigation artifacts.

The live UI fixture states explicitly that no 1601EQ Save, final-copy, or submission side effect occurred.
